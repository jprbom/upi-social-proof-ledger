# UPI Social Proof Ledger Design

## Product Thesis

A privacy-preserving proof layer that simulates receipt forensics, QR/VPA matching, duplicate proof detection, seller trust scoring, and dispute-ready GenAI explanations for social commerce.

## UX

The first screen is a usable role-aware product console, not a landing page.

## Backend

Express provides validated APIs, demo RBAC, rate limits, security headers, synthetic persistence, and a domain decision engine.
